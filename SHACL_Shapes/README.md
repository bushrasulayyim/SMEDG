# SHACL Shapes for SMEDG

This folder contains the SHACL shapes used to enforce the SMEDG information governance policies.

- **File:** `SHACL_Code.ttl`  
- **Content:** All SHACL NodeShapes and PropertyShapes used to operationalise the policy rules (P1–P48) and answer the competency questions (CQ1–CQ24).  
- **Purpose:** These shapes are loaded into the triple store to validate data and detect policy violations automatically.

The SHACL shapes are grouped and commented to align with the competency questions described in the Online Appendix tables.
