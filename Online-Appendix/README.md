# Online Appendix for "Ontology-Driven Policy Enforcement and Monitoring for SME Information Governance"

This folder contains all appendix materials referenced in the paper.

## Tables

- **Online Appendix Table 1:** Policy clause decomposition and mapping.
This table lists all 48 policy rules extracted from the organisation’s Information Security Classification and Handling Guide. Each rule is rewritten in plain English and represents an enforceable governance requirement. These rules form the foundation for the ontology classes, SHACL shapes, and SPARQL validation rules used in the SMEDG framework.
Purpose in the Framework:
Defines the core governance expectations for asset storage, handling, classification, retention, movement, and sharing.
Provides the baseline for mapping competency questions (CQ1–CQ24) to policy logic.
Serves as the authoritative reference for operationalising compliance checks.
Columns:
ID: Unique identifier assigned to each policy rule (P1–P48).
Policy Rule: Plain-language interpretation of the original policy clause.
