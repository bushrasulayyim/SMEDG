# SPARQL Validation Queries for SMEDG

This folder contains the SPARQL queries that retrieve violations detected by the SHACL shapes.

- **File:** `SPARQL_Code.ttl`  
- **Content:** A collection of SPARQL `SELECT` queries, one per competency question (CQ1–CQ24), each designed to list the assets, events, or records that breach a given policy rule.  
- **Purpose:** These queries are used to generate explainable, auditable outputs for monitoring dashboards and compliance reports.

Each query is aligned with the corresponding competency question and policy rules documented in the Online Appendix tables.
